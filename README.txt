SALES DATA MANAGER - run on Windows
1. Install Node.js LTS from https://nodejs.org (once).
2. Unzip this folder. Copy .env.example to .env and put your PostgreSQL password in PGPASSWORD.
3. Open Command Prompt in this folder (type cmd in the address bar) and run:
     npm install
     npm start
4. Open http://localhost:3000
The app reads your real sales_leads columns automatically.
